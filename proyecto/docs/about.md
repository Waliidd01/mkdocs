# Acerca de esta web

Esta página es una **wiki temática** dedicada a la marca **BMW**.  
Su objetivo es ofrecer una referencia clara y ordenada sobre historia, modelos, tecnologías y consejos básicos de mantenimiento.

### ¿Para quién es esta web?
- Estudiantes que preparan un proyecto temático.  
- Aficionados a la automoción.  
- Personas interesadas en conocer las diferencias entre gamas y tecnología BMW.

### Aviso
El contenido es con fines educativos y divulgativos. Las marcas pertenecen a sus respectivos propietarios.
